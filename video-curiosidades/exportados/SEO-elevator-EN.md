# Description
That "close door" button in the elevator? In a lot of elevators, it probably doesn't do anything. 🛗

In 1990, the Americans with Disabilities Act set rules so elevator doors stay open long enough for everyone to get in. Many close-door buttons were disabled or set to do nothing in normal mode, and the main ones they still work for are firefighters with a special key. It's called a placebo button, and crosswalk buttons in many big cities work the same way.

Do you still press it? 👇
