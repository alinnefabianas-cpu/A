# "7 weird things cats do" (estilo caderno rabiscado, em inglês, 16:9, 2:51)

> Padrão do canal de gatos: **todos os vídeos em inglês** (narração, legenda e textos na tela).

Mesmo motor do `video-gatos-miau` (papel pautado, traço tremido, marca-texto, post-its), com 20 cenas
e novos desenhos: gato de lado correndo, rato, passarinho, caixa, xícara, mesa, fantasma, casa e patinhas que amassam.

```bash
npm install && npm run audio
pip install edge-tts && python3 scripts/gerar-voz.py && node scripts/medir-voz.mjs
npm run render
```
O que vai para o YouTube está em `exportados/` (vídeo, 2 thumbnails, legenda .srt e SEO).
