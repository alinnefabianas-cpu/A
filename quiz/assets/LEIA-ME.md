# Logo oficial do Dopamine Rewire

Coloque aqui a imagem original da logo com o nome **`logo.png`** (de preferência quadrada, com pelo menos 512 × 512 px).

- A imagem é usada inteira, como um ícone de aplicativo com cantos arredondados, para que o fundo azul turquesa embutido não forme um quadrado destoante.
- Se houver uma versão com fundo transparente, salve-a como `logo-transparente.png`; ela será usada sobre os fundos claros.
- Sem o arquivo, o quiz mostra apenas o nome DOPAMINE REWIRE. O símbolo não é redesenhado.

Depois de adicionar a logo, rode `node scripts/brand-color.js` para extrair a cor turquesa predominante e atualizar as variáveis de cor em `quiz/quiz.css`.
